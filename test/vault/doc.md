# 引言

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它的设计目标是让纯文本更易读、易写，同时可方便地转换为 HTML。本文档用于验证 mini-outline 插件的标题识别与滚动同步功能。

## 基本语法

### 标题与段落

Markdown 使用 `#` 号来表示标题层级：一个 `#` 为一级标题，两个 `##` 为二级标题，依此类推。正文内容直接以纯文本形式书写即可。换行可以用两个空格加回车实现软换行，而空行则生成一个新的段落块。

### 列表与引用

无序列表使用 `-`、`*` 或 `+`，有序列表使用数字加点号。引用语句则以 `>` 开头，支持嵌套。代码可以使用反引号包裹表示行内代码，或使用三个反引号创建 fenced code block。

## 进阶用法

### 链接与图片

超链接格式为 `[文字](URL)`，图片则为 `[描述](URL)` 并在前面加一个感叹号。Typora 中粘贴图片或拖拽即可插入图片；链接如果以 `http` 开头则会被自动识别并高亮。

### 表格与脚注

表格通过管道符 `|` 分隔列、短横线 `-` 定义表头分割线，语法简洁但功能强大。脚注使用 `[^1]` 标注并在文档末尾给出说明内容。这些特性让 Markdown 在撰写技术文档时更加高效。

### 数学公式与图表

支持行内公式 `$E=mc^2$` 和独立显示的 `$$ ... $$` 块，基于 KaTeX 渲染。图表可以通过 Mermaid、PlantUML 等扩展语法嵌入，适合制作流程图、时序图和甘特图。Typora 的预览模式会实时渲染这些内容。

## 编辑器技巧

### 快捷键与多光标

Typora 提供了丰富的快捷键：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+K` 插入链接。按住 `Alt` 点击可创建多个光标，配合 `Shift+方向键` 可进行列选择。这些技巧大幅提升了长文档的编辑效率。

### 导出与发布

支持的导出格式包括 PDF、Word（docx）、HTML 和纯文本。导出时可以选择是否包含 CSS 样式；对于 HTML，Typora 还支持将样式内联或外链。配合 Pandoc 可以更灵活地转换到 LaTeX 或其他格式。

## 实践案例

### 博客与笔记

许多技术博主选择 Markdown + Typora 作为日常写作工具，因为其所见即所得的体验和无干扰的编辑模式非常适合长文创作。Obsidian、Notion 等现代笔记软件也都支持导入和导出 Markdown 文件。

### API 文档与 README

GitHub README、GitLab Wiki 以及各类 API 说明文档几乎都采用 Markdown 编写。配合自动化工具（如 Docusaurus、VitePress），可以一键生成静态站点，便于团队协作文档的维护与更新。

## 总结

Markdown 凭借其简洁语法和广泛兼容性，已成为当代文本编辑的事实标准之一。Typora 作为优秀的编辑器实现，配合社区插件体系进一步扩展了功能边界。mini-outline 正是为了提升长文档导航体验而诞生的辅助工具。
